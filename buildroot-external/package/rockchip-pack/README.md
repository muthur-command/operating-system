# rockchip-pack (host)

Vendored Rockchip tools for building `update.img` on Neardi LB200:

- `afptool`, `rkImageMaker` — firmware packer (`update.img`)
- `boot_merger`, `loaderimage` + `rkbin/` — `MiniLoaderAll.bin` / `uboot.img` for RK3576

Upstream: Rockchip Linux SDK (`tools/linux/Linux_Pack_Firmware`, `rkbin`).
